# AI Workplace Hub

Build a modern, responsive SaaS web application called AI Workplace Productivity Assistant.

Product Persona

Act as an expert SaaS product designer, UX/UI designer, and AI application developer.

The application is designed for busy professionals, office employees, managers, entrepreneurs, and team members who want to save time on repetitive workplace tasks.

The goal is to create one integrated AI workplace productivity platform that helps users write emails, summarize meetings, organize tasks, research topics, and get workplace assistance.

Main Navigation

Create a professional dashboard with a responsive sidebar containing:

Dashboard

Smart Email Generator

Meeting Notes Summarizer

AI Task Planner

AI Research Assistant

AI Workplace Chatbot

Settings

The sidebar should collapse into a mobile-friendly navigation menu on smaller screens.

Dashboard

Create a polished dashboard with:

Welcome message: "Work smarter. Save time. Get more done with AI."

Short explanation of the application

Five feature cards

Clear icons and "Open Tool" buttons

Professional productivity SaaS styling

Feature cards:

Smart Email Generator

Meeting Notes Summarizer

AI Task Planner

AI Research Assistant

AI Workplace Chatbot

Smart Email Generator

Create a page where users can:

Enter what they want the email to communicate

Select a tone: Formal, Friendly, Professional, Persuasive, Concise

Enter optional key points

Click "Generate Email"

Show the AI response in an editable output panel.

Include:

Copy

Edit

Regenerate

Clear

The AI should preserve the user's meaning, use professional language, and never invent important information.

Meeting Notes Summarizer

Allow users to paste meeting notes.

Generate clearly separated sections:

Executive Summary

Key Discussion Points

Decisions Made

Action Items

Deadlines

Do not invent people, decisions, tasks, or deadlines. If information is missing, state that it was not specified.

Make the output editable and copyable.

AI Task Planner

Allow users to enter multiple tasks and optional deadlines.

The AI should:

Prioritize tasks

Identify urgent tasks

Categorize them as High, Medium, or Low

Suggest a realistic daily or weekly schedule

Allow the generated schedule to be edited

The AI should provide recommendations rather than making decisions for the user.

AI Research Assistant

Allow users to enter a workplace-related topic or question.

Generate:

Topic Overview

Key Points

Insights

Advantages

Challenges

Recommendations

Follow-up Questions

Do not claim that sources were consulted unless actual sources are available.

AI Workplace Chatbot

Create a modern chat interface where users can ask workplace productivity questions.

The chatbot should behave as a professional workplace productivity assistant.

Include:

User messages

AI responses

Input field

Send button

Loading state

Clear conversation option

AI Prompt Engineering

Use structured AI prompts based on:

Role

Context

Task

Constraints

Output format

The AI should provide clear, concise and professional responses and should not invent information.

Responsible AI

Include a visible disclaimer:

"AI-generated content may contain errors or omissions. Review and verify important information before using it for workplace decisions or communication."

The application should encourage users to verify important information and avoid entering sensitive confidential information.

UI/UX

Create a clean, modern, professional SaaS interface.

Use:

Professional blue/purple color palette

White/light neutral backgrounds

Rounded cards

Subtle shadows

Modern icons

Clear typography

Consistent spacing

Accessible contrast

Minimal, tasteful animations

Make the application fully responsive for desktop, tablet and mobile.

User Experience

Every AI tool should have:

Clear instructions

Helpful placeholder examples

Loading states

Friendly error states

Editable AI outputs

Copy functionality

Regenerate functionality where appropriate

Do not create unnecessary features.

Prioritize a polished, professional interface and a clear structure that can later be connected to real AI functionality.
